# Osage Lagtrain Wallpaper

Win11 24H2 B&W cycles wallpaper - portable.

Quick start:
  1. Extract OsageLagtrain.zip to any folder (e.g. D:\tmp\Osage\)
  2. Run OsageLagtrain.exe
  3. Create scenes: Copy-Item -Recurse cycles\_template cycles\my_scene ; edit scene.json

See cycles/README.md, docs/ffmpeg-recipe.md, CREDITS.txt.
