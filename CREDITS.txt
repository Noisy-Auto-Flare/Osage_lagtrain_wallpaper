Usage / Использование:

  - See docs/ffmpeg-recipe.md for yt-dlp + ffmpeg commands (mpdecimate, crop, eq=saturation=0).

Template / Шаблон:
  cycles/_template/scene.json — id: template_scene, fps: 12, mode: once, holdLastMs: 800
  cycles/_template/0001.png   — 1x1 pixel #b2b2b2 placeholder, valid PNG binary (69 bytes)
  Copy _template to create your own scene: Copy-Item -Recurse cycles/_template cycles/my_scene

Instructions / Инструкция:
  1. Read docs/ffmpeg-recipe.md and extract frames locally.
  2. Place frames as cycles/<your_id>/0001.png, 0002.png, ... (natural sort, 0001..9999).
  3. Edit cycles/<your_id>/scene.json — set your id, fps, mode.
  4. Replace this CREDITS.txt note if you use a different source — keep the fair-use warning.
